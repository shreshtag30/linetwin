    Mechanisms

    1. Bottleneck detection. Active Period Method — longest continuous active run wins. A breakdown does not end an active period. Benchmarked over 30 scenario×seed trials: Busy Ratio 90.0%, Active Period 86.7%. Reported as measured, not ranked to flatter the deployed method — Busy Ratio still edges the one we deploy.
    2. Defect risk. Monotone (non-negative-constrained) logistic regression, Platt-calibrated, reported at its own MCC-tuned operating point.
    3. Sensor-gap inference. Eight dark stations solved from a graph equation over their neighbours, tagged inferred — N% where N is an exact partition of unity.
    4. Rolling horizon. Live state forked and fast-forwarded ~30 sim-minutes, once a second.
    5. Genealogy. Per-unit event log walked backward from inspection, realigned by cumulative transfer delay.

    Reported at the model's own MCC-tuned threshold, not a round number chosen to look good. Low recall is the deliberate trade: at this operating point the model stays quiet unless the congestion signal is strong, because an alert feed that cries wolf is worse than no alert feed.

    Small absolute numbers, published rather than a headline accuracy. Defects are rare — no-skill scores 0.008 PR-AUC here — so the honest comparison is against that floor and against the cycle_time_z baseline, which is the single feature actually fitted for comparison. The label-generating process was published in docs/DATA.md before any of this was computed against it, and that label is linear by construction — so a linear model winning here is partly an artefact of the synthetic process, stated plainly rather than claimed as a general result.

    Where it breaks

    • Inference recovers a dark station's cycle-time trend, never whether a specific unit was defective.
    • Model B's label is linear by construction, so a linear model being the best fit is partly an artefact of the synthetic label — not evidence it would win on real defect data.
    • Model B's features do not yet consume the graph layer's inferred values.
    • Consecutive active periods are autocorrelated, so the significance test's independence assumption does not strictly hold. Annotated, not suppressed.
    • The leadership figure is an estimate from named assumptions.
